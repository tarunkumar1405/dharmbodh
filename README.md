# DharmBodh

DharmBodh.co.in starter website.

## Main files
- index.html — homepage
- style.css — design
- script.js — dynamic homepage
- data/ — articles, quiz, mantras, dharma knowledge and festivals
- articles/ — individual article pages
- pages/ — category and policy pages
- robots.txt / sitemap.xml — search-engine basics

## AdSense
The supplied Google AdSense Auto Ads script has been added to the HTML pages.
Before publishing ads, make sure the AdSense account/site is approved and Auto Ads is enabled in the AdSense dashboard.
